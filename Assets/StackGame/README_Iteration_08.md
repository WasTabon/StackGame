# README — Iteration 8: Бонусы (Swap, Destroy, Shuffle)

## Новые скрипты

### BonusManager.cs
Три бонуса с ограниченным количеством:

**SWAP (2 шт)** — поменять 2 слоя местами
- Нажать SWAP → выбрать первый слой → Confirm → выбрать второй → Confirm
- Слои плавно меняются позициями, затем авто-проверка матчей
- Пополняется при цепной реакции x3+

**DEL (2 шт)** — удалить один слой без матча
- Нажать DEL → выбрать слой → Confirm
- Вспышка → частицы → сжатие → падение → авто-проверка
- Пополняется при цепной реакции x2+

**MIX (1 шт)** — перемешать все слои случайно
- Нажать MIX → мгновенное выполнение
- Все слои анимированно перестраиваются → авто-проверка
- Пополняется при цепной реакции x4+

**Отмена**: нажать ту же кнопку повторно или Escape

**Пополнение**: цепные реакции дают новые бонусы (настраиваемо в Inspector)

### Изменённые скрипты
- **InputController.cs** — интеграция BonusManager: Confirm сначала проверяет активный бонус, Escape отменяет. Добавлен IsLocked() и GetSelectedIndex()

## UI
Три кнопки справа по центру экрана (вертикальный стак):
- Каждая показывает название + количество
- Пульсация при получении нового бонуса
- Оранжевая подсветка при активном режиме
- Серые если 0 штук

## Настройки в Inspector (BonusManager)
- **swapCount / destroyCount / shuffleCount** — начальные количества
- **chainForSwap** (3) — минимальная цепь для получения Swap
- **chainForDestroy** (2) — минимальная цепь для получения Destroy
- **chainForShuffle** (4) — минимальная цепь для получения Shuffle
